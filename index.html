认知任务线上实验

全程约 25–30 分钟 · 需要电脑和键盘 · 请一次性做完

本实验包含三个连续的认知任务：颜色命名任务（看到词语后按对应颜色键）、词语记忆与再认任务（先记一组词，再做新旧判断）、类比推理任务（完成"A 之于 B，相当于 C 之于 ？"的类推题）。

参加前请确认

  • 使用电脑参加，不要用手机或平板（任务依赖键盘反应，手机记录的数据不可用）
  • 使用 Chrome 或 Edge 浏览器，关闭其他占用资源的程序
  • 全程约 25–30 分钟，中途不要刷新页面或切换窗口，否则当前部分的数据会作废
  • 实验开始后会进入全屏，请按提示操作；如遇全屏失败，请按 F11 手动进入全屏
  • 请在安静环境中一次做完，期间不要离开座位

编号用于区分不同被试，必须填写。请在招募通知、群公告或主试私聊里找到你的编号；没有编号请先联系主试，不要自行编造。

建议在安静、网络稳定的环境中一次性完成 · 数据仅用于学术研究
